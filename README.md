# IMG421Assignment5
Mission Demolition
Game Description

Mission Demolition is a physics-based projectile game where the player uses a slingshot to launch a ball and break through structures to reach a goal zone.

This version expands the original class prototype by introducing three fully distinct difficulty modes, each with unique mechanics, visuals, and gameplay behavior. The player selects a difficulty from a title screen, and each mode alters how the slingshot, environment, and objectives behave to create varied experiences rather than simple scaling difficulty.

The game emphasizes trajectory control, environmental interaction, and visual feedback, allowing players to refine their shots using a real-time trajectory indicator while engaging with different material types and physics responses.


How to Interact

Click and drag the slingshot to aim and control launch power. Release to fire the ball.

The player must:

Aim using the trajectory preview indicator
Adjust power and angle to navigate obstacles
Land the ball inside the goal zone box to win

Gameplay includes:

Real-time trajectory prediction
Physics-based collisions
Different wall behaviors depending on material

Features
Three distinct difficulty modes (Easy, Medium, Hard)
Title screen with mode selection UI
Return-to-menu option after win/loss
Physics-based slingshot system
Real-time trajectory visualization
Large, forgiving goal zone system
Material-based wall interactions:
Solid walls (durable)
Bouncy walls (high elasticity)
Glass walls (breakable)
